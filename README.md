# IT Operations Runbooks

A personal collection of practical IT operations, troubleshooting guides, useful commands, and step-by-step runbooks based on hands-on IT support experience.

## Purpose

This repository serves as a personal knowledge base for documenting technical issues, diagnostic procedures, solutions, and operational tasks.

Each runbook is written to be:

- Clear and easy to follow
- Practical and reusable
- Tested whenever possible
- Safe for public use
- Updated when procedures change

## Categories

- Windows
- Networking
- FortiGate
- Microsoft 365
- Windows Server
- Printers
- Hardware
- Scripts and Tools

## Runbook Structure

Runbooks may include:

1. Overview
2. Symptoms
3. Possible Causes
4. Requirements
5. Diagnostic Procedure
6. Resolution
7. Validation
8. Rollback
9. Escalation
10. Security Considerations
11. References
12. Document Control

## Important Notice

All examples in this repository are sanitized before publication.

Company names, usernames, passwords, internal IP addresses, confidential configurations, and other sensitive information are not included.

Always review commands and procedures before applying them in a production environment.
